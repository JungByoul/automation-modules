# weekly-plan 스킬

## Role
사용자(별)의 **월요일 오전 루틴**을 재현하는 에이전트.
전주 회고(to-do)와 금주 공유(주간보고)를 입력받아 **이번주 개인업무 계획**을 txt + pptx로 산출.

> 선행 단계(스티커메모 → 메모장 복붙 → `2.10_TODO`에 주차 txt 저장)는 **사용자가 이미 끝낸 상태로 전제**함. 이 스킬은 "전주 to-do txt가 폴더에 이미 있다"에서 시작한다.

doc-writer 스킬과 성격이 같음(입력물 → 정형 산출물). 파일 네이밍·주차 표기·python 스택을 그대로 재사용.

## 파일 읽기
- **to-do txt**: 그대로 Read.
- **주간보고 docx**: python-docx로 전체 텍스트 추출. "이하 속기록" 원문까지 포함해 읽어 맥락을 잡을 것(정리본만 보면 뉘앙스가 빠짐).
  ```python
  from docx import Document
  print("\n".join(p.text for p in Document(path).paragraphs))
  ```

## 내용 추출 규칙
- **전주 to-do** → 미완/이월 항목, 여러 날 반복 등장한 과제(= 계속 끌고 가는 핵심 과제) 식별.
- **주간보고** → 금주 ActionItem, 일정(오픈·마감·연차·면접·출장 등), 본인 담당 추정 항목.
- **전역 규칙 준수(CLAUDE.md)**:
  - 사실이 아닌 것은 `[추론]`·`[가설]`·`[미확인]` 표기. 본인 담당 여부가 불명확하면 단정하지 말 것.
  - 예: 회의록에 "교육자료 세팅"만 있고 담당자 미기재면 → `본인 담당 [추론]`.

## 초안 구조 (txt)
```
================================================
이번주 개인업무 계획 — N월M주차 (YYMMDD 월 ~ YYMMDD 금)
작성일: YYYY-MM-DD / 작성자: 별
================================================

[이번주 전제]        연차/가용일, 주요 외부 일정(오픈 등)
[이번주 최우선]      ★ 2~3개 + 각 근거
[일자별 계획]        월~금, 연차일 명시, ★=최우선 표기
[이번주 ActionItem]  회의 연계
[백로그 / 기한 여유]
================================================
```
- 연차·반차 등 가용일 제약을 **전제**에 먼저 명시하고, 그에 맞춰 마감성 업무를 앞 요일로 당겨 배치.
- 외부 일정(사장님 출장 등)은 **본인 업무와 연관될 때만** 기준으로 삼을 것. 무관하면 배치 기준으로 쓰지 말 것.

## ★ 정정 왕복 (이 스킬의 본질)
초안은 **완성본이 아니라 대화의 출발점**이다. 실제로 사용자는 초안에서 상당 부분을 뒤집는다
(예: 외부 일정 기준 삭제, 작업 통합, 마감일 재조정, 불필요 항목 제거).

1. 추출·초안을 먼저 **채팅으로 보여주고** 사용자 피드백을 받는다.
2. 피드백 반영 → 수정본을 다시 확인받는다. (필요하면 반복)
3. **사용자가 "확정"하기 전에는 절대 파일로 만들지 말 것.** (CLAUDE.md "계획 합의 후 단계별 진행")

## pptx 생성 (표지 없음 · 2페이지)
보조 스크립트 `weekly_ppt.py`(이 스킬 폴더 내)를 사용. **레이아웃 코드는 고정**이고, 상단 `PLAN` 딕셔너리와 `OUT_PATH`만 그 주 내용으로 채운 뒤 실행.

- 1페이지: 전제 박스 + 최우선 카드 2개(파란 헤더)
- 2페이지: 월~금 5열 카드(연차일은 회색) + 하단 ActionItem 바
- `★`로 시작하는 항목은 붉은 볼드로 자동 강조.
- 폰트 "맑은 고딕", 16:9.

실행:
```powershell
# PLAN / OUT_PATH 를 그 주 값으로 수정한 뒤
python "C:\Users\정별\.claude\skills\weekly-plan\weekly_ppt.py"
```
> 매주 PLAN을 직접 수정하는 대신, 스크립트를 복사해 scratchpad에서 돌려도 됨. 단 레이아웃(함수 `build`)은 바꾸지 말 것 — 주차 간 일관성 유지가 목적.
> python-pptx 미설치 시: `python -m pip install python-pptx`.

## 실행 플로우
1. 오늘 날짜 확인 → 입력 2개 자동 탐지 → **경로 제시 후 사용자 확인**.
2. 두 파일 읽기(docx는 속기록 원문까지).
3. 미완·이월·금주 ActionItem·일정 추출 → txt 초안 작성.
4. **채팅으로 초안 제시 → 사용자 정정 왕복 → 확정.**
5. 확정 후 txt 생성(저장 폴더).
6. 확정 txt 기준으로 `weekly_ppt.py`의 PLAN·OUT_PATH 채워 pptx 생성.
7. 두 산출물 경로 안내.
