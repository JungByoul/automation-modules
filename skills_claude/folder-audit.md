# folder-audit

사용자의 WBS 폴더 구조를 점검하고, 문제를 수정하며, 문서(folder_structure.md + memory)를 최신 상태로 유지하는 스킬.

## 핵심 경로

| 항목 | 경로 |
|------|------|
| WBS 루트 | `C:\Users\정별\` |
| 규칙 문서 | `C:\Users\정별\0_Claude_md\0.1_local_folder\folder_structure.md` |
| Memory | `C:\Users\정별\.claude\projects\C--Users---\memory\env_folder_wbs.md` |
| WBS 스캔 설정 | `C:\Users\정별\3_Dev\3.2_Memo_automation\wbs_routing.json` |

---

## Step 1 — 스캔

PowerShell로 아래 루트를 depth 3까지 스캔한다.

```powershell
$roots = @("1_Work", "2_Personal", "3_Dev", "4_Resources")
foreach ($r in $roots) {
    Get-ChildItem "C:\Users\정별\$r" -Directory -Recurse -Depth 2 | Sort-Object FullName
}
```

동시에 `folder_structure.md`를 읽어 문서상 기대 구조를 파악한다.

---

## Step 2 — 문제 탐지

아래 규칙에 맞지 않는 폴더를 모두 찾아 심각도별로 분류한다.

### WBS 번호 규칙

```
[대분류].[그룹번호][그룹내순번]_이름
예) 1.10_Onboarding  →  1.10.00_최초온보딩  (하위 항목)
```

**2자리 서브번호 규칙** (핵심):
- 단독 항목: `x0` 형식 — `00`, `10`, `20`, `30`…
- 서브 계열: `x1`, `x2`… — 예) `31`, `32` = 3번 슬롯의 교육 계열 1, 2번
- 1자리(`0`, `1`, `2`…)는 규칙 위반

**prefix 규칙**:
- `1.20_S-oil_Projects` 하위 폴더는 반드시 `1.20.`으로 시작해야 함
- prefix 없는 폴더(예: `00_개인_작업시트`, `oo`)는 규칙 위반

**구조 규칙**:
- 항목 번호 폴더(예: `1.30.00_나만의_메뉴얼`)는 그룹 폴더(`1.30_나만의_메뉴얼`) 안에 있어야 함
- 그룹 폴더 없이 항목 폴더가 상위 레벨에 바로 있으면 구조 오류

**네이밍 규칙**:
- 구분자는 `_` 사용, 공백 금지
- 쉼표(`,`)는 열거 목적으로 허용
- 그 외 특수문자는 오류

### 무시 목록
`최초_존재_기능들`, `Desktop`, `Downloads`, `.claude`, `.vscode` 등 시스템/숨김 폴더는 점검 제외.

### 심각도 분류

| 심각도 | 기준 | 예시 |
|--------|------|------|
| 🔴 구조 | 번호 체계 자체를 깨는 것 | 그룹 폴더 없이 항목 폴더가 잘못된 위치에 있음 |
| 🟡 명명 | 번호 자리수·prefix 불일치 | 1자리 번호, prefix 누락 |
| 🟢 문서 | 실제는 맞지만 MD에 반영 안 됨 | 새 폴더가 folder_structure.md에 없음 |

탐지된 문제가 없으면 "이상 없음"을 보고하고 Step 4(문서 동기화)만 진행한다.

---

## Step 3 — 수정 (대화형)

문제를 심각도 순(🔴→🟡→🟢)으로 처리한다.

**각 문제마다:**
1. 현재 상태와 제안 변경을 명확히 보여준다
2. 사용자 승인을 받은 후 실행한다
3. 이름이 불명확하거나 의도를 알 수 없는 경우 반드시 먼저 물어본다

**실행 방법:**
- Rename: `Rename-Item "원래경로" "새이름"`
- 이동: `Move-Item "원래경로" "대상경로"`
- 폴더 생성: `New-Item -ItemType Directory "경로"`

**열린 파일 오류 처리:**
파일이 열려 있어 이동/rename 실패 시 → 해당 파일 이름을 알려주고 닫아달라고 요청 후 재시도. 강제 종료하지 않는다.

**절대 건드리지 않는 것:**
- `최초_존재_기능들` 폴더와 그 하위
- `.claude\` 하위 파일 (memory 업데이트 제외)

---

## Step 4 — 문서 동기화

수정 완료 후 두 파일을 업데이트한다.

### folder_structure.md 업데이트
실제 폴더 구조를 다시 스캔하여 트리 섹션을 현실에 맞게 수정한다.
변경된 폴더명, 새 폴더, 삭제된 폴더를 반영한다.

### memory(env_folder_wbs.md) 업데이트
`## WBS 구조` 섹션의 트리와 날짜를 오늘 날짜로 갱신한다.
번호 규칙 설명이 실제와 다르면 함께 수정한다.
