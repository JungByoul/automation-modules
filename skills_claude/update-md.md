# update-md

사용자의 CLAUDE.md 전역 지시 파일을 정밀하게 편집하는 스킬.

## 파일 위치

`C:\Users\정별\.claude\CLAUDE.md`

## 워크플로우

### 1. 현재 파일 읽기
CLAUDE.md 전체를 읽어 현재 구조와 섹션을 파악한다.

### 2. 변경 의도 파악
사용자가 무엇을 바꾸려는지 이해한다. 진짜 모호한 경우에만 질문 — 대부분은 맥락에서 파악 가능.

변경 유형 분류:
- **규칙 추가**: 새 섹션 또는 기존 섹션 내 새 항목
- **규칙 수정**: 기존 텍스트 일부 교체
- **예시 추가/수정**: 기존 예시 포맷·어조에 맞춰 삽입
- **섹션 삭제/이동**: 구조 변경

### 3. 편집 위치 특정
파일 전체를 고치지 말고, 변경이 필요한 최소 범위를 찾는다.
- 기존 섹션이 있으면 그 안에 삽입
- 새 섹션이 필요하면 논리적 위치 제안 (왜 거기인지 한 줄 설명)

### 4. Before / After 제시
편집 전후를 명확히 보여준다:

```
[변경 전]
기존 텍스트...

[변경 후]
수정된 텍스트...
```

### 5. 확인 후 적용
사용자 확인을 받은 뒤 Edit 툴로 정밀 편집.  
완료 후: 변경된 섹션 이름과 줄 번호 범위 한 줄로 안내.

## 원칙

- **최소 범위 편집**: 파일 전체 재작성 금지. Edit 툴로 해당 부분만.
- **어조 보존**: 사용자 문체를 그대로 유지. 요청 없으면 표현 개선 금지.
- **예시 포맷 일관성**: 기존 예시가 있으면 동일한 포맷 사용.
- **위치 제안 시 이유 명시**: "왜 이 섹션에 넣는지" 한 줄.
